🌿 About GrazingTrack v4.0

Free and open source rotational grazing management for farmers.

✅ Draw fields or auto-split from farm boundary
✅ Edit any field — name, type, colour, rest target
✅ Fence-line guided camp splitting
✅ Day / Night dual grazing cycle
✅ Live rainfall overlay (Open-Meteo, free)
✅ PDF farm report
✅ GeoJSON export for QGIS and other GIS tools
✅ Offline PWA — installs on phone and desktop
✅ MIT licence — free forever, no accounts
